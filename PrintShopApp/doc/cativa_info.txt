# Captive portal and Mobile Hotspot notes

Windows Mobile Hotspot provides Wi-Fi authentication and NAT. PrintShop does not
provide an open Wi-Fi network or packet-level Internet filtering.

The integrated LinkShare service provides:

- DNS handling for captive-portal discovery
- HTTP redirect to /scan
- Wi-Fi approval and session tracking
- Internet-status checks

The service is started by src/main_app.py through LinkShare/src/captive_portal_service.py.
There is no standalone LinkShare server. HTTPS, DoH, VPN bypass prevention, and
firewall policy enforcement require separate network-layer controls.
