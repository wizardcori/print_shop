실행 중 생성되는 항목
----------------------
- .venv/: Python 가상 환경
- LinkBox/LinkBox_Files/: 업로드된 파일
- LinkShare/fare/: 암호화된 이용권·세션 로그
- wifi_approval_settings.ini: 통합 앱의 SSID와 Fernet 키 설정
- dist/ 또는 각 모듈의 dist/: PyInstaller 결과물

INI 설정 섹션
-------------
- [Settings]: 핫스팟 SSID, 핫스팟 이미지 경로, 이용권 로그 폴더, 최대 연결 수
- [Network]: 인터넷용 NIC와 핫스팟용 무선 NIC의 이름·IP, 핫스팟 IPv4 CIDR 대역과 게이트웨이
- [Storage]: 업로드 폴더, 구역 목록, 저장 탭 목록
- [Security]: LinkShare Fernet 암호화 키

참고
----
- 통합 앱의 Flask 라우트는 LinkShare/templates/portal.html과
  LinkShare/templates/file_share.html을 참조한다. 현재 저장소에는 해당 템플릿이
  포함되어 있지 않으므로 /scan 및 /file_share 화면을 사용하려면 템플릿을 추가해야 한다.
- cert.pem과 key.pem은 배포 환경마다 새로 생성하는 것을 권장한다.
